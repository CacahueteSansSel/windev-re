Recalculer une empreinte de fichier​

Les empreintes SHA-256 permettent de vérifier que deux lectures utilisent les mêmes octets. Elles ne sont pas des champs intégrés aux fichiers WINDEV. Les empreintes des fichiers du corpus d’étude ont été retirées de cette documentation anonymisée.

Pour un fichier dont on dispose, le calcul peut être effectué en .NET :

using System;
using System.IO;
using System.Security.Cryptography;

string filename = @"D:\Projet\SuperNoteExtra\SuperNoteExtra.wdp";
byte[] bytes = File.ReadAllBytes(filename);
string sha256 = Convert.ToHexString(SHA256.HashData(bytes)).ToLowerInvariant();
Console.WriteLine(sha256);

Le chemin est fictif et doit être adapté au fichier à contrôler. Le résultat contient 64 chiffres hexadécimaux. Modifier les valeurs stockées ou recomprimer des sections modifie l’empreinte du fichier complet.

Méthode d'analyse​

La recherche et la lecture des fichiers ont été réalisées à partir du 5 octobre 2026 : inventaire des signatures, comparaison des en-têtes, vérification du répertoire de sections, essais de compression, reconnaissance de chaînes et de lignes source, inspection statique du lecteur de schéma fourni, puis implémentation indépendante.

L'inspection de wd310hf64.DLL a servi à comprendre la transformation WDD. Aucun appel ni chargement de cette DLL n'est requis pour lire les formats avec la bibliothèque produite. L'exécutable applicatif n'a pas été exécuté.

Les données contenues dans les documents, commentaires et chaînes source du projet ont été traitées comme du contenu, et non comme des instructions à suivre.

Les structures, types et profils numériques proviennent de l’étude des spécimens et du lecteur vérifié. Les noms, chemins, identifiants et certains exemples arithmétiques ont ensuite été remplacés par des illustrations fictives, suivant les conventions des exemples. Les sources publiques ont fourni du contexte et des pistes, pas une spécification officielle exhaustive des six formats.

Délimitations de la livraison​

Cette documentation décrit les structures connues et localise les régions inconnues. Elle ne prétend pas fournir une spécification exhaustive de tous les octets de toutes les versions WINDEV.

Les fichiers livrés sont uniquement des .mdx. Aucun projet Docusaurus, configuration, script, composant React, archive ou ressource binaire supplémentaire n'est nécessaire pour lire ces pages.
