# Formats de fichiers

Les formats sont illustrés par deux projets fictifs : **SuperNoteExtra**, logiciel de prise de note, et **SuperMailExtra**, logiciel de client mail. Les [conventions](./01-conventions.mdx#exemples-fictifs) précisent le rôle des profils numériques et des valeurs anonymisées.
