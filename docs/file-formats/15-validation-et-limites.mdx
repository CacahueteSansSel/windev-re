Ils ne transforment pas une région opaque en région comprise et ne certifient pas toutes les versions majeures de WINDEV.

| Niveau | Invariant contrôlé |
| --- | --- |
| Fichier | Signature, révision et taille bornée |
| Répertoire PCS | Nombre de sections et frontières cohérentes |
| Sections | Somme des longueurs couvrant exactement le fichier |
| Enveloppe | Longueurs encodée/décodée et frontière dans le buffer |
| LZW | Codes valides, taille produite exacte et code de fin dans le dernier octet déclaré |
| WDD | Mots de variante, somme de contrôle, comptes, noms dupliqués et table propriétaire |
| WLangage | Tag de ligne, chaînes encadrées, auteur et douze octets de métadonnées |
| Propriétés de fenêtre | Descripteur 610 et nom racine reconnus avant application des offsets connus |

## Limites mémoire du lecteur actuel

Les valeurs suivantes sont des budgets configurables de l'implémentation, pas des constantes du format :

| Option | Valeur par défaut | Unité / commentaire |
| --- | --- | --- |
| Taille maximale du fichier | 134 217 728 | Octets, soit 128 Mio |
| Taille maximale d'un bloc décodé | 67 108 864 | Octets, soit 64 Mio |
| Total maximal de données décodées | 268 435 456 | Octets, soit 256 Mio |
| Nombre maximal de blocs décodés | 4 096 | Blocs |
| Taille maximale d'une chaîne | 4 194 304 | Octets, soit 4 Mio ; pour une chaîne encadrée, le contrôle porte sur la taille totale |
| Nombre maximal de sections accepté | 256 | Limite de lecture du conteneur |

Les versions majeures autres que 28 et 31 sont refusées par défaut. L'option d'essai de versions non testées n'est pas une garantie de compatibilité des structures internes.

## Recalculer une empreinte de fichier

Les empreintes SHA-256 permettent de vérifier que deux lectures utilisent les mêmes octets. Elles ne sont pas des champs intégrés aux fichiers WINDEV. Les empreintes des fichiers du corpus d’étude ont été retirées de cette documentation anonymisée.

Pour un fichier dont on dispose, le calcul peut être effectué en .NET :

```csharp
using System;
using System.IO;
using System.Security.Cryptography;

string filename = @"D:\Projet\SuperNoteExtra\SuperNoteExtra.wdp";
byte[] bytes = File.ReadAllBytes(filename);
string sha256 = Convert.ToHexString(SHA256.HashData(bytes)).ToLowerInvariant();
Console.WriteLine(sha256);
```

Le chemin est fictif et doit être adapté au fichier à contrôler. Le résultat contient 64 chiffres hexadécimaux. Modifier les valeurs stockées ou recomprimer des sections modifie l’empreinte du fichier complet.

## Méthode d'analyse

La recherche et la lecture des fichiers ont été réalisées à partir du 5 octobre 2026 : inventaire des signatures, comparaison des en-têtes, vérification du répertoire de sections, essais de compression, reconnaissance de chaînes et de lignes source, inspection statique du lecteur de schéma fourni, puis implémentation indépendante.

L'inspection de `wd310hf64.DLL` a servi à comprendre la transformation WDD. Aucun appel ni chargement de cette DLL n'est requis pour lire les formats avec la bibliothèque produite. L'exécutable applicatif n'a pas été exécuté.

Les données contenues dans les documents, commentaires et chaînes source du projet ont été traitées comme du contenu, et non comme des instructions à suivre.

## Repères d'inspection statique

Ces adresses sont des positions relatives dans **la DLL fournie de cette version précise**. Elles ne sont pas des offsets dans un fichier WDD, WDP ou WDW, et ne sont pas utilisées par le lecteur autonome :

| Position relative dans la DLL | Routine identifiée |
| --- | --- |
| `0x4F85C8` | Paramétrage du buffer d'analyse hérité |
| `0x50D6B0` | Dérivation de clé |
| `0x50D410` | Transformation inverse d'octets |
| `0x4F88A0` | Lecture de l'en-tête du schéma |

## Délimitations de la livraison

Cette documentation décrit les structures connues et localise les régions inconnues. Elle ne prétend pas fournir une spécification exhaustive de tous les octets de toutes les versions WINDEV.

Les fichiers livrés sont uniquement des `.mdx`. Aucun projet Docusaurus, configuration, script, composant React, archive ou ressource binaire supplémentaire n'est nécessaire pour lire ces pages.
