WindevReader est une bibliothèque .NET 10 de lecture seule. Elle ouvre les fichiers avec du code autonome : aucun composant officiel WINDEV n’est chargé.

Le parcours conseillé est [installer](./installation.mdx), [ouvrir un fichier](./premiers-pas.mdx), puis choisir le guide correspondant au résultat recherché.

| Objectif | Guide |
| --- | --- |
| Lire les références d’un projet, le source et les propriétés d’interface | [Projets, fenêtres et procédures](./documents-windev.mdx) |
| Lire un schéma et nommer les valeurs du FIC PERSONNE | [Schéma et données HFSQL](./schema-et-donnees.mdx) |
| Exporter un BMP ou une ressource de patch | [Images et bibliothèques WDL](./extraction.mdx) |
| Utiliser la bibliothèque depuis le terminal | [Commandes CLI](./cli.mdx) |
| Trouver une classe, une propriété ou une méthode | [Référence de l’API](./reference-api.mdx) |
| Comprendre un refus, une limite ou un diagnostic | [Erreurs et compatibilité](./erreurs-et-limites.mdx) |

Les guides décrivent la version **0.12.1**. Les [formats de fichiers](../file-formats/index.mdx) donnent les structures binaires derrière ces API. Les noms applicatifs des exemples sont fictifs : le logiciel de prise de note SuperNoteExtra et le logiciel de client mail SuperMailExtra.


Le code livré suit les règles de `AGENTS.md` : types explicites, identifiants et commentaires en anglais, variables en camel case et séparation des étapes. Les classes de lecteurs sont réparties dans leurs propres fichiers ; les codecs et lecteurs communs restent dans `Internal/`. Les noms des méthodes publiques sont conservés.
