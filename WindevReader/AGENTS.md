## Coding Style

Write the code as readable as possible. One can and should be able to read the code easily.
Specify every type (do not use the var keyword), separate each code "section" (like variable declarations, loops, method calls, etc.) with one blank line return.
Make the code as readable as possible and write comments only if the code really needs explaining.

In the source code, the comments needs to be written in plain English.

Variables needs to be named clearly in lowercase camel case.

The code MUST be clear and simple to understand and to work on later with or without AI.

Source code & comments MUST be written in proper English.
