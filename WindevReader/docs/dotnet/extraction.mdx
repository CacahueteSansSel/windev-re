## Exporter la prévisualisation d’une fenêtre

```csharp
using WindevReader;

WdwWindevWindow window = WdwWindevWindow.Open("FEN_Notes.wdw");

if (window.Preview is { } image)
{
    image.SaveBmp("previsualisation.bmp");

    Console.WriteLine($"{image.Width} × {image.Height}");

    byte[] pixels = image.GetRgba32();
}
```

`BmpData` contient le BMP décompressé complet. `SaveBmp` conserve ces octets ; `GetRgba32` produit un tableau RGBA orienté de haut en bas, avec alpha 255. Les dimensions de certains gabarits peuvent différer de `Bounds`. Cette API restitue l’image stockée dans le WDW ; elle ne redessine pas la fenêtre.

## Inventorier un patch

```csharp
WdlWindevLibrary patch = WdlWindevLibrary.Open("SuperNoteExtra.wdl.1.0.77.0.6");

foreach (WindevLibraryEntry entry in patch.Entries)
{
    Console.WriteLine($"{entry.Index}: {entry.LogicalName}, " +
        $"ressource={entry.IsResource}, segments={entry.Chunks.Count}");
}
```

Le lecteur reconnaît le patch fourni de révision 3102. Le suffixe numérique ne change pas son type PCS.

## Extraire une ressource

```csharp
WindevLibraryEntry resource = patch.Entries.Single(e => e.OriginalPath == "ARCHIVE.PNG");
byte[] contenu = patch.ReadResource(resource);

File.WriteAllBytes("archive-extraite.png", contenu);
```

`ReadResource` traite les ressources directes ou LZW reconnues. Les chemins internes à l’archive restent des métadonnées ; l’appelant choisit le fichier de sortie. `ReadStoredChunk(entree, segment)` renvoie un segment tel qu’il est stocké dans l’archive.

## Consulter une fenêtre compilée

```csharp
WindevLibraryEntry windowEntry = patch.Entries.Single(e => e.LogicalName == "FEN_Journal");
WindevDecodedBlock properties = patch.ReadWindowProperties(windowEntry);

Console.WriteLine(properties.DecodedByteLength);
```

Ce résultat est un buffer de propriétés reconnu, pas un WDW source reconstruit. Le bytecode compilé n’est pas décompilé en WLangage.
