# Formats binaires étudiés

La documentation détaillée est organisée dans `file-formats/index.mdx`, avec une sous-section WINDEV et une sous-section HFSQL. Chaque page donne les positions en octets, les types et les limites des profils reconnus.

La lecture de la bibliothèque est expliquée dans `dotnet/index.mdx`. Le cas PERSONNE et son analyse sont détaillés dans `file-formats/hfsql/fic.mdx`. Les exemples applicatifs utilisent deux logiciels fictifs : SuperNoteExtra et SuperMailExtra.
